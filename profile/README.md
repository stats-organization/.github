# Stats Organization

GitHub organization maintaining the
[GitHub Readme Stats](https://github.com/anuraghazra/github-readme-stats)
ecosystem, created to make maintenance and collaboration easier.

We currently maintain:
- [github-readme-stats-action](https://github.com/stats-organization/github-readme-stats-action) — GitHub Action used as a recommended way to generate GitHub Readme Stats.
- [github-stats-extended](https://github.com/stats-organization/github-stats-extended) (fork) — the [extended](https://github.com/stats-organization/github-stats-extended/blob/master/docs/fork.md) and actively maintained successor of github-readme-stats. This is also used internally by `github-readme-stats-action`.
- [github-readme-stats](https://github.com/stats-organization/github-readme-stats) (fork) — maintenance fork where [next](https://github.com/stats-organization/github-readme-stats/tree/next) is the active release branch which we may periodically backport to upstream.
- [github-readme-stats](https://github.com/anuraghazra/github-readme-stats) (upstream) — the <!--stable -->reference repository<!-- we keep in sync-->.
- Supporting tooling used by the project.

The github-stats-extended fork has diverged significantly from the upstream github-readme-stats project and has become our main focus. If time allows we aim to also do maintenance on the original github-readme-stats project.
